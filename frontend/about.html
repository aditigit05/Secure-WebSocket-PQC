🔐 Secure PQC Chat

Post-Quantum Secure Chat

A real-time chat app designed for the future: messages are encrypted on the client, the server only routes ciphertext, and no chat history is stored.

Terms and Conditions
  • All messages are end-to-end encrypted to ensure only the sender and receiver can read them.
  • Session keys are quantum-safe, generated using Kyber (post-quantum cryptography).
  • Messages are not permanently stored on any server. Temporary data exists only for message delivery.
  • User data (email and session token) is used exclusively for authentication purposes.
  • Users must not share session tokens or attempt to bypass any security mechanisms.
  • Users are expected to use the app ethically and legally.
  • Unauthorized access or attempts to break encryption are strictly prohibited.

About

PQC (Kyber) AES Session E2EE WebSocket No History
🛡️
End-to-End Encryption
All messages are encrypted on the sender’s device and decrypted only by the recipient. Ensures complete privacy, as no server stores unencrypted messages.
🧪
Post-Quantum Key Exchange
Session keys are generated using Kyber, a post-quantum cryptography (PQC) algorithm. Even future quantum computers cannot break these keys.
⚡
Real-time Messaging
Messages are sent and received instantly using WebSocket connections.The server validates your session token before accepting your connection.
🧼
No Message History
Session-only display; refresh clears chat. Messages are end-to-end encrypted and only exist in RAM during the session.
👾
AES Encryption for Messages
After the quantum-safe session key is established via Kyber, messages are encrypted using AES, a symmetric encryption algorithm.
🤖
Privacy-Focused Design
Emails and session tokens are used only for authentication. Messages are temporary and deleted after delivery.
